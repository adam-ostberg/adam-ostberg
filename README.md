## Selected work 💻

- **[Matjakt](https://adamostberg.com/projects/matjakt/)**: my bachelor's thesis, built with three classmates. It scrapes 4.3 million prices from around 500 Swedish grocery stores and works out the cheapest way to buy a whole shopping list. *Python, Scrapy, Playwright, PostgreSQL, React, TypeScript.* [Live demo](https://matjakt.org/)
- **[Product matcher](https://github.com/adam-ostberg/product-matcher)**: is ICA or Coop cheaper? ICA's product data has no barcodes, so I built a labeling tool, hand-labeled 424 products and trained an XGBoost model to find the same product in both stores (89% precision on a held-out test set). Across 7,659 matched products, Coop is cheaper on 49% and ICA on 24%. Uses the data from Matjakt. *Python, pandas, scikit-learn, XGBoost, React.*
- **[Student dropout prediction](https://adamostberg.com/projects/student-dropout-prediction/)**: five classifiers that predict whether a student graduates or drops out, plus a small app so we could ask it about ourselves. *Python, scikit-learn, XGBoost, pandas.*
- **[Bolagsrättsligt Forum](https://adamostberg.com/projects/bolagsrattsligt-forum/)**: Client work. The website and sign-up form for a course in company and securities law, which I built and ran on my own for five years. *HTML, CSS, JavaScript, Firebase.*
